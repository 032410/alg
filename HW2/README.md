# HW2 — 遞迴式：精確解與 Big O

求出下列四個遞迴式的精確解（或Big O），並說明推導過程。

- 驗證程式：[`recurrence.py`](recurrence.py)（`python recurrence.py`）

## 答案總覽

| # | 遞迴式 | 精確解 | Big O | 遞迴樹的重點 |
| --- | --- | --- | --- | --- |
| 1 | `T(n) = T(n-1) + 8,  T(1) = 1` | `8n - 7` | **Θ(n)** | n 層，每層 1 個節點做 O(1) |
| 2 | `T(n) = 2T(n-1) + 9, T(1) = 1` | `5·2ⁿ - 9` | **Θ(2ⁿ)** | n 層，每層節點數 ×2 |
| 3 | `T(n) = 2T(n/2) + 1,  T(1) = 1` | `2n - 1` | **Θ(n)** | log₂n 層，共 n 個節點做 O(1) |
| 4 | `T(n) = T(n/2) + 1,   T(1) = 1` | `log₂n + 1` | **Θ(log n)** | log₂n 層，共 1 個節點做 O(1) |

> #3、#4 的精確解假設 **n 是 2 的冪**（才能整除到 1）。n 不是 2 的冪時，
> 精確解會有取整數的小誤差（例如 `T(n) = 2·2^⌊log₂n⌋ - 1`），但 Big O 結論不變。

## #1 `T(n) = T(n-1) + 8, T(1) = 1`

**展開（逐層代換）**

```
T(n) = T(n-1) + 8
     = T(n-2) + 8 + 8
     = T(n-3) + 8 + 8 + 8
     ...
     = T(1) + 8(n-1)
     = 1 + 8(n-1)
T(n) = 8n - 7
```

**Big O**：`n → ∞` 時 `8n - 7 ≈ 8n`，常數 8、7 都不影響成長速率 → **O(n)**。

**意義**：每呼叫一次只多做一件小事，深度 n、每層 1 個節點，總工作量就是 n。
這就是 `for i in range(n): total += 8` 的遞迴版。

**驗證**：`T(1)=1`、`T(2)=9`、`T(4)=25`、`T(8)=57` ✓

---

## #2 `T(n) = 2T(n-1) + 9, T(1) = 1`

**方法 A：換元消去常數項**

令 `S(n) = T(n) + 9`：

```
S(n) = T(n) + 9
     = 2T(n-1) + 9 + 9
     = 2(T(n-1) + 9)
     = 2S(n-1)          ← 變成乾淨的等比遞迴
S(1) = 1 + 9 = 10
⇒ S(n) = 10 · 2^(n-1)
⇒ T(n) = 10 · 2^(n-1) - 9 = 5 · 2^n - 9
```

**方法 B：齊次解 + 特解**（教科書標準作法）

- 齊次解 `T_h(n) = C · 2ⁿ`（特徵根 r² = 2r → r = 2）
- 特解設為常數 `A`：`A = 2A + 9 ⇒ A = -9`
- 通解 `T(n) = C · 2ⁿ - 9`，代入 `T(1) = 1`：`2C - 9 = 1 ⇒ C = 5`

⇒ **`T(n) = 5 · 2ⁿ - 9`**

**Big O**：**O(2ⁿ)**。

**意義**：這就是 HW1 的「方法 2a」`f(n) = f(n-1) + f(n-1)` 的計時模型 ——
呼叫次數 2ⁿ，所以 n=100 時需要 2¹⁰⁰ ≈ 1.27×10³⁰ 次呼叫，跑不出來。
一般化：`T(n) = a·T(n-1) + b`（a ≥ 2）→ **Θ(aⁿ)**。

**驗證**：`T(1)=1`、`T(2)=11`、`T(4)=71`、`T(8)=1271`、`T(16)=327671` ✓

---

## #3 `T(n) = 2T(n/2) + 1, T(1) = 1`

**遞迴樹分析**

- 樹高：`n → n/2 → n/4 → … → 1`，共 **log₂n 層**
- 葉節點數：`2^(log₂n) = n` 個，每個 O(1) → 合計 `n`
- 內部節點第 i 層有 `2^i` 個，每個做 O(1)，i = 0 … log₂n-1：

```
T(n) = (2^0 + 2^1 + … + 2^(log₂n-1)) + n
     = (2^(log₂n) - 1) + n
     = (n - 1) + n
T(n) = 2n - 1
```

**用代數求精確解**：令 `k = log₂n`、`S(k) = T(2ᵏ)`

```
S(k) = 2S(k-1) + 1,  S(0) = T(1) = 1
S(k) = 2^(k+1) - 1
T(n) = 2^(log₂n + 1) - 1 = 2n - 1            ✓
```

**Big O**：**O(n)**。

**Master theorem 對照**（a=2, b=2, f(n)=1）：

- `log₂2 = 1`，`n^(log_ba) = n`
- `f(n) = 1 = O(n^(1-ε))`（ε = 1）→ **Case 1** → `Θ(n^(log_ba)) = Θ(n)` ✓

> ⚠️ **常見陷阱**：有人會套 Case 2 得到 `Θ(n log n)`，那是錯的。
> Case 2 要求 `f(n) = Θ(n^(log_ba) · log^k n) = Θ(n log^k n)`，
> 而這裡 `f(n) = 1`，不满足 Case 2；`1` 符合 Case 1（比 `n` 小得多），所以答案是 `Θ(n)`。

**意義**：把問題**砍半**比一個一個處理快。`T(n) = 2T(n/2) + 1` 就是 HW1 的
「方法 2a + 查表」：呼叫次數從 2ⁿ 降到 2n，但一次呼叫的成本變高，總量仍是線性。

## #4 `T(n) = T(n/2) + 1, T(1) = 1`

**遞迴樹分析**

- 樹高：**log₂n 層**（`n → n/2 → … → 1`）
- 只有一條分支，每層 1 個節點做 O(1) → 總共 `log₂n + 1`

```
T(n) = T(n/2) + 1 = T(n/4) + 2 = … = T(1) + log₂n = 1 + log₂n
```

⇒ **`T(n) = log₂n + 1`**

**Big O**：**O(log n)**。這就是「每次把 n 砍一半，要砍幾次才到 1」的次數，
例如二分搜尋。

**Master theorem 對照**（a=1, b=2, f(n)=1）：

- `log₂1 = 0` → `n^(log_ba) = n⁰ = 1`
- `f(n) = 1 = Θ(1 · log⁰n)` → **Case 2（k = 0）** → `Θ(n⁰ log n) = Θ(log n)` ✓

> ⚠️ **常見陷阱**：Case 1 會給出 `Θ(n^0) = Θ(1)`，但那是錯的。
> Case 1 要求 `f(n) = O(n^(log_ba - ε)) = O(n^-ε)`，也就是 `f` 要比 `1/n^ε` 還小；
> `f(n) = 1` 辦不到，所以這裡是 Case 2 而不是 Case 1。

---

## 為什麼「精確解」能直接看出 Big O

把精確解在 `n → ∞` 時只留主要項（低階項、常數項都可忽略）：

| 精確解 | 去掉低階項 | 主要項成長速率 | Big O |
| --- | --- | --- | --- |
| `8n - 7` | `8n` | 線性 | `O(n)` |
| `5·2ⁿ - 9` | `5·2ⁿ` | 指數 | `O(2ⁿ)` |
| `2n - 1` | `2n` | 線性 | `O(n)` |
| `log₂n + 1` | `log₂n` | 對數 | `O(log n)` |

驗證方法：看 `T(n) / 成長項` 是否**收斂成一個常數**（`recurrence.py` 的輸出）：

```
         n     #1 T(n)/n   #2 T(n)/2^n     #3 T(n)/n   #4 T(n)/log2(n)
        16        7.5625        4.9999        1.9375            1.2500
       256        7.9727        5.0000        1.9961            1.1250
      4096        7.9983        5.0000        1.9998            1.0833
     65536        7.9999        5.0000        2.0000            1.0625
```

四個比值都趨近固定值（8、5、2、1），代表估的複雜度**剛好好**（Θ），
若比值一直暴增就代表 Big O 估太小了。

## 重點整理

1. 兩種展開方式：**(a) 逐層代換**適合 `n-1` 型；**(b) 遞迴樹 / Master theorem** 適合 `n/2` 型。
2. `T(n) = a·T(n-1) + b`：`a ≥ 2` → `Θ(aⁿ)`；`a = 1` → `Θ(n)`。
3. `T(n) = a·T(n/b) + f(n)`：先看遞迴樹有幾層（`log_b n`），
   再算「每層工作總量」和「葉節點數」，兩者相加就是精確解。
4. Master theorem 的兩個易錯點（本題 #3、#4 都踩到）：
   Case 1 要 `f(n)` 比 `n^(log_ba)` **小得多**（差一個 `n^ε`）；
   `f(n) = 1` 配 `log_ba = 1` 是 Case 1，配 `log_ba = 0` 卻是 Case 2（k=0）。
5. 常數項（這裡的 8 和 9）不影響 Big O，只影響精確解的係數。
