# 第一題：用迭代法求解自訂問題

## 問題

> 求方程式 `x³ - x - 1 = 0` 在區間 `(1, 2)` 的實根。

選這個問題的理由：

- `f(x) = x³ - x - 1` 連續，且 `f(1) = -1 < 0`、`f(2) = 5 > 0`，由**介值定理**知 `(1, 2)` 內必有實根 → 迭代法收斂的目標明確。
- 三次方程沒有「一步到位」的代數解（雖然可以用 Cardano 公式，但很難背），必須靠迭代。
- 這個根叫**塑膠常數**（plastic number）`α = 1.3247179572447458…`，是幾何上最「無關」的比例（正五邊形的對角線與邊長比），可拿來核對誤差。

## 迭代法的原理

迭代法（fixed-point iteration）就是把「找根」改寫成「找一個不動點」：

```
x_(k+1) = g(x_k)
```

只要 `g` 滿足收斂條件，就會有一個 `α` 讓 `g(α) = α`，而 `x_k` 會愈來愈靠近它。

**收斂條件（局部）**：`|g'(α)| < 1`。也就是說，在根附近如果走一步只會走「原來誤差的 |g'(α)| 倍」，
誤差會愈來愈小；反之 `|g'(α)| > 1` 會被推開而發散。

**收斂階數 p**：`|x_(k+1) - α| ≈ C · |x_k - α|^p`。p 越大越快：

| p | 例子 | 誤差從 10⁻¹ 到 10⁻¹² 要幾步 |
| --- | --- | --- |
| 1（線性） | 不動點迭代、二分法、EM | 12 / log₂(1/0.19) ≈ 3（每次縮 0.19）…實測 17 步 |
| 1.618（超線性） | 割線法 | 實測 7 步 |
| 2（二次） | 牛頓法 | 6 步 |

## 寫出五種迭代式，結果差很多

| 迭代式 | 改造自 | 迭代函數 | `\|g'(α)\|` | 收斂？ | 步數 | 階數 p |
| --- | --- | --- | --- | --- | --- | --- |
| g1 | `x³ = x + 1` | `x + 1` | 1.0000 | **否** | 60（用盡） | — |
| g2 | `x³ = x + 1` | `∛(x + 1)` | 0.1899 | 是 | 17 | 1.001 |
| g3 | `x(x²-1) = 1` | `1/(x² - 1)` | 4.6494 | **否** | 11（爆掉） | — |
| g4 牛頓法 | `x - f/f'` | `x - (x³-x-1)/(3x²-1)` | 0（極小） | 是 | **6** | 1.999 |
| g5 割線法 | 割線法 | 用最近兩點決定斜率 | 0（但無導數） | 是 | 7 | 1.571 |

觀察重點：

1. **g1 `x + 1`**：從最直接的代數變形出來，卻每步固定加 1，`|g'| = 1` → **永遠收斂不到**。
   寫錯一個代數變形，演算法就從 O(log) 變成「永不停止」。
2. **g3 `1/(x²-1)`**：`|g'(α)| = 4.65 > 1`，在根附近會被彈出去，數值在 ±0.8 ~ ±21 之間亂跳。
3. **g2 `∛(x+1)`**：`|g'| = 0.19 < 1` 會收斂，但每次只縮到原來的 0.19 倍 → **17 步**。
4. **g4 牛頓法**：`|g'(α)| = 0`，代表誤差被**平方**。第 5 步就已經是對的十位有效數字 → **6 步**。
5. **g5 割線法**：不用導數（微分在題目條件下可能算不出來時很有用），階數 1.571 ≈ 黃金比例。

**最終答案：`x = 1.324717957244746`**（牛頓法 6 步，與真值差 2.22e-16）

## 對應題目範例

題目給的 `f1 = 3/x`、`f2 = x - 1/4(x²-3)`、`f3 = 1/2(x + 3/x)` 其實是同一個問題的三種迭代式，
我的 g1~g5 是一模一樣的觀念：

| 範例 | 對應 | 問題 | 結果 |
| --- | --- | --- | --- |
| `f1(x) = 3/x` | g3 類 | `x² = 3` | **震盪不收斂**：`1 → 3 → 1 → 3…`，`|g'(√3)| = |−3/x²| = 1` |
| `f2(x) = x - (x²-3)/4` | g4 牛頓法 | `x² = 3` | 二次收斂 |
| `f3(x) = (x + 3/x)/2` | 質根法 | `x² = 3` | 二次收斂（牛頓法的變體） |

`f1` 是最典型的反例：**`|g'(α)| = 1` 時迭代值會在兩個點之間來回震盪**，
`x1 = x2 = x3 = 1` 起步時 `f1` 會永遠停在 1 和 3 之間。

## 重點整理

1. 迭代法能不能用，看 `|g'(α)|`：`< 1` 收斂、`> 1` 發散、`= 1` 震盪或停滯。
2. `|g'(α)|` 越小收斂越快（g2 的 0.19 vs 牛頓法的 0）。
3. 想把線性收斂升級成二次收斂，就要讓 `g'(α) = 0` → **牛頓法的設計重點就是這個**。
4. 不用導數時用**割線法**（階數 1.618），或用**二分法**（最穩但每步只有 1 bit，階數 1）。
5. 收斂階數 p 決定速度：誤差要小 d 位數，步數約 `log(d)/log(p)`。
6. 初始值也會影響成敗：g3 從 1.0 出發會 `1/(1-1)` 除以零，所以要選 1.5。

# 第二題：經典迭代演算法的統一抽象框架

## 設計

`generic_iterator(transition_func, is_converged, initial_state, max_iter)`
把每個演算法都拆成兩件事，框架只負責「重複執行 + 判斷何時停」：

```python
state = initial_state
for iteration in range(max_iter):
    next_state = transition_func(state)          # ← 這個演算法特有的「怎麼走下一步」
    if is_converged(state, next_state, iteration):  # ← 這個演算法特有的「何時算收斂」
        return next_state, iteration + 1
    state = next_state
```

好處：

- **換演算法不用重寫迴圈**，9 個演算法共用同一份收斂/計數/逾時邏輯。
- `state` 是「不關心型別」的（**泛型**）：純量（牛頓法）、`np.ndarray` 向量（冪次迭代）、
  `np.ndarray` 矩陣（QR）、`tuple`（RK4 的 `(t, y)`）都能塞進去。
- 這就是**模板方法（Template Method）** + **策略注入（Strategy）** 的組合：
  框架是模板，`transition_func` / `is_converged` 是注入的策略。
- 副作用：收斂準則是外部傳進來的，所以「怎麼算收斂」必須由使用者負責，
  框架無法替你保證收斂（但有 `max_iter` + 警告）。

## 九個示範

| # | 演算法 | 解決的問題 | `transition` | `is_converged` | 狀態型別 | 本機結果 | 迭代 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 二維不動點迭代 | 解 `X = MX + c` | `0.5X₀-0.2X₁+0.3, 0.2X₀+0.5X₁+0.4` | `‖new-old‖ < 1e-6` | 向量 | `[0.241379, 0.896552]` | 23 |
| 2 | 牛頓法 | `x² - 4 = 0` | `x - f(x)/f'(x)` | `\|new-old\| < 1e-6` | 純量 | `2.000000` | 5 |
| 3 | 高斯-賽得爾法 | 解線性方程組 `Ax=b` | 逐行就地消元、更新 `xᵢ` | `max\|new-old\| < 1e-6` | 向量 | `[2.25, 2.0, 3.75]` | 9 |
| 4 | 冪次迭代法 | 主特徵向量/特徵值 | `Av/‖Av‖` | `allclose(old,new)` | 向量 | `λ = 4.721570` | 17 |
| 5 | QR 演算法 | 所有特徵值 | `R⁻¹·A·R`（QR 分解再乘回） | 非對角元素總和 `< 1e-6` | 矩陣 | `[5.732051, 2.267949, 1.0]` | 19 |
| 6 | 龍格-庫塔 RK4 | ODE `dy/dt = y-t+1` | 一階 4 級 Taylor 組合 | `t ≥ t_end` | tuple `(t,y)` | `t=2.0, y=9.388889` | 10 |
| 7 | PageRank | 網頁權重 | `r ← G·r` | `‖r_new-r‖ < 1e-6` | 向量 | `[0.3246, 0.2251, 0.2251, 0.2251]` | 15 |
| 8 | K-Means | 2D 聚類（k=2） | E-step 分配 + M-step 更新中心 | `max\|new-old\| < 1e-6` | 矩陣 | `[[1.826, 1.798], [-2.114, -2.128]]` | 4 |
| 9 | EM（兩枚硬幣） | 估計 `θ_A, θ_B` | E-step 期望計數 + M-step 更新 | 兩參數變化 `< 1e-6` | tuple | `θ_A=0.7968, θ_B=0.5196` | 16 |

## 逐個說明

### 1. 二維不動點迭代

解的是線性方程組 `X = MX + c`，也就是第一題「把方程改寫成不動點」的矩陣版本。
收斂條件：`|λ(M)| < 1`（這裡 M 的特徵值是 `0.5 ± 0.2i`，模長 ≈ 0.539 < 1，所以會收斂）。

**驗證**：解 `(I - M) X = c` 得 `[0.24137931, 0.89655172]`，與迭代結果一致 ✓

### 2. 牛頓法求根

第一題 g4 的同款。要注意從 `x0 = 1` 起步：若從 `x0 = 0` 開始，`f'(0) = 0` 會除以零。

**驗證**：`x = 2`，而真值就是 2 ✓（5 步：二次收斂的典型速度）

### 3. 高斯-賽得爾法

解 `Ax = b`，差別在於同一輪裡**就地更新**：算 `x₂` 時直接用到剛更新的 `x₁`（雅可比疊代）。
對角佔優（diagonally dominant）時保證收斂。

**驗證**：`np.linalg.solve(A, b) = [2.25, 2.0, 3.75]`，與迭代結果完全相同 ✓

### 4. 冪次迭代法（冪法）

每次把向量投影到 `A` 上再正規化：矩陣冪 `Aᵏv₀ = Σ cᵢλᵢᵏvᵢ`，當 k 夠大時**被最大特徵值那一項主導**，
方向收斂到主特徵向量。

**驗證**：`np.linalg.eigvalsh(A) = [1.880087, 2.398343, 4.721570]`，最大特徵值 4.721570 ✓

### 5. QR 演算法

`A₀ = QR` → `A₁ = RQ`，重複做，特徵值會「跑到對角線上」。QR 演算法是所有特徵值演算法的骨幹
（`np.linalg.eig` 底層就是類似手法；對稱矩陣則縮成 Lanczos/分治三對角化）。

**驗證**：`np.linalg.eigvals(A) = [5.732051, 2.267949, 1.0]` ✓（此例剛好有整數特徵值 1）

### 6. 龍格-庫塔 RK4

把 ODE 轉成迭代：`state = (t, y)`，每一步用 4 個斜率加權推進（`k1 + 2k2 + 2k3 + k4`）· h/6。
**這裡的收斂判定換成「到達終點」**——迭代步數是事先知道的（`t_end/h = 10` 步），
代表框架的 `is_converged` 也可以表達「跑完預定工作」而不只是「數值收斂」。

**驗證**：`y' = y - t + 1, y(0)=1` 的解析解是 `y = t + eᵗ`，`y(2) = 9.389056`，
RK4（h=0.2）給 9.388889，誤差 1.7e-4，符合四階方法的 `O(h⁴)` 誤差 ✓

### 7. PageRank

`G = d·M + (1-d)/n` 是加了「隨機衝浪」的轉移矩陣（`d = 0.85` 機率點連結、15% 機率亂跳），
權重就是 `G` 的**平穩向量**（特徵值 1 的特徵向量），用冪次迭代求出來——和第 4 個示範是同一套技術。

**驗證**：迭代 2000 次得 `[0.324561, 0.225146, 0.225146, 0.225146]`，總和 = 1 ✓

> ⚠️ 兩個值得注意的細節：
> 1. 這裡的 `M` 是**列和為 1**（把 `r` 當行向量看），所以要解的是 `G r = r`。
> 2. 因為第 3、4 頁的傳入連結完全一樣，`I - G` 是**奇異矩陣**（`np.linalg.cond ≈ 2.6e16`），
>    用 `np.linalg.solve(G, ...)` 會直接噴出 4.3e15 的垃圾；
>    冪次迭代反而穩定地找出平穩向量。**這就是產業界不用解聯立方程式算 PageRank 的原因**。

### 8. K-Means（Hard EM）

每輪做兩件事：E-step 用「最近中心」分派標籤（hard），M-step 用各組平均更新中心。
收斂很快（4 輪），因為中心點移動的幅度本來就小。

**注意**：K-Means **對初始值敏感**（隨機初始化可能得到不同的局部解），
而且只保證單調下降、不保證全域最佳 —— 這是 EM 系列的共同弱點。

### 9. EM 演算法（兩枚硬幣）

資料是 5 次拋硬幣的正面/反面次數，但**不知道每次是哪一枚**（潛在變數）。
E-step 計算「這次是 A 幣的機率」作為權重，M-step 用加權總數更新 `θ`：

**驗證**：把同一組 E/M 步驟跑 500 次得 `θ_A = 0.7967890669, θ_B = 0.5195831201`，
與框架跑 16 次的 `0.7968 / 0.5196` 相同 ✓

> 順帶一提：直覺上 33/50 = 0.66 應是 A 幣的機率，但因為有幾組「差異很小」的觀測
> （例如 5:5 無法分辨是哪枚），演算法判斷那些是 B 幣的，讓 A 幣上調到 0.80、B 幣下調到 0.52。

## 框架的風險與注意事項

| 議題 | 說明 | 對應示範 |
| --- | --- | --- |
| 不保證收斂 | `transition` 壞掉就會發散，框架只會跑到 `max_iter` 然後印警告 | 1、7 |
| 收斂準則要自己負責 | 用 `‖new-old‖` 當準則時，若解不唯一（如奇異系統）會收斂到錯的答案 | 7 |
| 需要歸一化 | 冪次迭代若不除 `‖Av‖`，數值會 overflow | 4 |
| QR 無 shift 會失敗 | 含複數/負特徵值時收斂很慢，實務上用 shifted QR | 5 |
| 局部解 | K-Means / EM 只保證單調下降到局部極值 | 8、9 |
| 收斂 ≠ 正確 | QR 收斂到「近上三角」就停了，不代表特徵值已排好序 | 5 |
| 狀態不可變 | `is_converged` 若直接改到 `state`，框架行為會怪異（要用新物件賦值） | 3（`x.copy()`） |

## 重點整理

1. **迭代法的共同骨架**：狀態 → `transition` → 收斂判定 → 重複。用框架統一這三步，
   換演算法只換 `transition` 與 `is_converged`。
2. **從線性到二次**：把 `|g'(α)|` 壓到 0（牛頓法）就能把線性收斂升級成二次收斂，
   誤差位數每多 1 位，步數只多 `1/2`。
3. **同一個數學核心反覆出現**：`2T(n/2)+1` 的計時模型、Householder/QR 的正交化、
   SVD 的 `Aᵏv` 主導效應、PageRank 的平穩向量、K-Means/EM 的交替最佳化 ——
   都是「迭代到定點為止」。
4. 實務上選演算法的順序：**先看問題結構（線性？矩陣？機率模型？）→ 再看收斂條件 → 最後才比速度**。
